# Modern Developer Portfolio

A highly visual, premium personal portfolio website showcasing projects, skills, education, and career experience, built using React, TypeScript, and MagicUI.

## Interactive Features
- **MagicUI Highlights**: Retro terminal command output emulation, border beams, and animated marquee grids.
- **Smooth Navigation**: Anchor scroll utilities guiding viewport transitions to specific sections.
- **Responsive Viewport Hook**: Detects and optimizes layouts dynamically for mobile, tablet, and desktop viewports.
- **Social Configuration Schema**: Dynamic configurations schema validation validating email and profile links.

## Technologies Used
- React + TypeScript
- Vite
- Tailwind CSS
- MagicUI
- Vercel Deployment Configurations
